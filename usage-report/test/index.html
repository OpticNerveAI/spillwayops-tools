usage-report tests

Each case loads the usage report, ../index.html, in a frame, drops fixture files from this directory on it through its file input, takes the steps a reader would, and checks what the page then shows against figures worked out by hand from the fixture. README.md says where each fixture's format comes from. Every fixture is synthetic. The page must be served over HTTP, for example with python3 -m http.server from the repository root.
