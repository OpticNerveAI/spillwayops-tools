Usage report

Reads a per-member usage CSV from GitHub Copilot, Claude Code, Cursor, Codex or any other vendor and shows how usage is distributed: how much the heaviest fifth of members draws, who is at or over an allowance, whose allowance went unused, and how many seats recorded no usage. Two exports are recognized by their header row. Any other file goes through a column mapper that you confirm. The files are parsed in this page. Nothing is uploaded and this page makes no network requests of any kind.

Drop one or more CSV files here, or

Files up to 20 MB each. Several files are combined when their header rows are identical, and a file can be added to the set at any time.

    Where each vendor's export comes from, and what it does not carry

    Each statement below is written from the vendor documentation it links. The two vendor tools published beside this one, the Copilot billing report and the Claude spend report, read the same two files with the same verified presets. No Cursor or Codex export has been verified yet, so those files go through the column mapper, and a preset for either is added only after a real export or the vendor's documented column list has confirmed the header row.

    GitHub Copilot

    Where it comes from. An organization owner or billing manager requests the billing usage report from GitHub under Settings → Billing & licensing → Usage. No token is needed. Since June 2026, consumption is metered in AI credits pooled at the billing entity, at one credit per cent, and the pool resets on the first of each month with unused credits forfeited.

    What it does not carry. The billing usage CSV is recognized here by its header row and carries each user's recorded monthly quota, so the allowance tiles come from the file. It is not the Copilot activity report, which lists seat activity with no consumption figures; that file is named and refused. The usage dashboard and the metrics API are a different view of the same activity, updated within two full days, dependent on telemetry being enabled in each developer's IDE, and excluding Copilot Chat on GitHub.com and GitHub Mobile.

    Sources: GitHub Docs, Usage-based billing for organizations and enterprises; GitHub Docs, Copilot metrics and the usage dashboard.

    Claude Code

    Where it comes from. An Owner or Primary Owner exports the spend report from claude.ai under Settings → Analytics → “How much is Claude costing?” → Export spend report, choosing month to date, last month, the last 90 days or a custom range. The export lists each member's use of each model with requests, prompt and completion tokens, and net and gross spend, summed over the window. Spend data refreshes daily with a one-day delay. On Enterprise plans, Admins can open Analytics but cannot view spend, so they cannot export this file.

    What it does not carry. On Team and seat-based Enterprise plans the spend report covers usage-credit spend only, which appears once usage credits are turned on, so it reads who is buying past the seat allowance and how much, not consumption inside it, because usage inside the allowance is not metered in dollars. The file has no date column and no per-member limit; a limit you type is compared with every member. The Claude Code analytics export under Analytics → Claude Code carries member emails and lines of code with no spend, and this tool names it and stops.

    Sources: Claude Help Center, View usage analytics for Team and Enterprise plans; Claude Help Center, Manage usage credits for Team and seat-based Enterprise plans; Claude Code Docs, Manage costs effectively.

    Cursor

    Where it comes from. On Teams, an Admin opens the dashboard's analytics: a daily usage chart over the preceding 365 days with a CSV download per chart, filtered to at most ten users and 90 continuous days at a time, with data collected only from clients on version 1.5 or higher. Members have no access to the admin dashboard. On Enterprise, the Admin API returns per-user on-demand spend in cents, total spend including included usage, daily per-user usage over at most 30 days and per-request usage events; it needs an API key and is not called by this page.

    What it does not carry. One chart at a time and ten users per filter means a team of forty is at least four files, exported from the same chart with the same columns. Drop them together: this tool combines files whose header rows are identical and counts any row that appears in more than one file, though two exports that overlap without a date column cannot be told apart beyond exact duplicates. No Cursor export has been verified against this tool, so the mapper opens and you confirm which column is the member and which is the amount. Included usage and on-demand spend are separate figures in Cursor's dashboard; label the unit with whichever the chart you exported shows.

    Sources: Cursor Docs, Analytics; Cursor Docs, Admin API; Cursor Docs, Members, Roles, and Seat Types; Cursor Docs, Team Pricing.

    Codex

    Where it comes from. On ChatGPT Business, workspace analytics shows usage by member, including seat type, credits spent and messages sent, over seven days, one month, six months, twelve months or a custom window, and Owners download usage reports under Billing. On Enterprise, the Admin Console breaks credit spend down by user, product and model, with a Cost API and CSV exports covering up to twelve months, with data lagging by one to 24 hours.

    What it does not carry. Usage inside a seat's five-hour and weekly windows is not metered in dollars; only usage past them draws credits, at a rate card in credits per million tokens. What a credit costs in dollars depends on the plan or agreement, and no cited page prices a Business credit, so this tool never supplies a dollar rate for Codex credits; type one only if your agreement states it. No Codex export has been verified against this tool, so the mapper opens; documented column names such as seat type and credits spent are pre-selected when they match, and you confirm each choice.

    Sources: OpenAI Help Center, ChatGPT Business Release Notes; OpenAI Help Center, Flexible pricing for the Enterprise, Edu, and Business plans; OpenAI, New usage analytics and updated spend controls for enterprises; OpenAI Help Center, Workspace analytics for ChatGPT Enterprise and Edu; OpenAI Help Center, ChatGPT Rate Card (Business, Enterprise/Edu credit-based pricing); ChatGPT Learn, Pricing.
